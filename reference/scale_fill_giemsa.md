# Giemsa stain fill scale for ideograms

Grayscale band colors by Giemsa stain intensity, with highlighted
centromeres, variable regions, and stalks.

## Usage

``` r
scale_fill_giemsa(...)
```

## Arguments

- ...:

  Other arguments passed to
  [`ggplot2::scale_fill_manual()`](https://ggplot2.tidyverse.org/reference/scale_manual.html),
  e.g. `values` to override individual stain colors.

## Value

ggplot2 scale
