# ggGenomicTracks: Build genomic track visualizations within the ggplot2 framework

The 'ggplot2' universe of visualization in R provides extensive
customization of plots and their components. 'ggGenomicTracks' bridges
the gap between the 'ggplot2' extensions to create genomic track or
browser-like stacked plots at loci of interest.
